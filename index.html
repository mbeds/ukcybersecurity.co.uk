Common Questions

Security & Threat Intelligence FAQ

Clear answers on independent auditing, daily CVE tracking, Azure lockouts, and phishing traps.

Why separate independent testing from IT support?

When the same provider builds your systems and grades their own work, blind spots go unchallenged. We provide testing and advisory only—giving directors an unbiased assessment with zero product upsells.

How does daily asset inventory and CVE checking work?

We catalogue every website, server, plugin, router, and cloud service you run and check that inventory daily against newly disclosed CVE vulnerabilities so critical flaws are patched before automated scanners hit them.

How do Azure IP restrictions and timed lockouts stop attacks?

Restricting Microsoft Entra ID (Azure AD) logins to trusted UK IP ranges, enforcing phishing-resistant MFA, and applying timed lockouts after failed sign-ins stops automated password-spraying and overseas login attempts.

How does an unused admin@ address act as a phishing trap?

An unadvertised decoy inbox such as admin@yourdomain.com that no legitimate supplier emails acts as an early-warning tripwire—any message arriving there immediately exposes active phishing or spoofing campaigns targeting your domain.
